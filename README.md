# SITCON 2027 年會主題討論

這個 repository 用來進行 SITCON 2027 年會主題的公開討論與整理。

討論的重點不是比誰先提出完整主題，而是讓觀察、問題與未完成的想法能被其他人延伸、拆分、重新組合，逐步形成可支撐整場年會的主題方向。

## 怎麼參與

請到 Discussions 參與討論。

你可以：

- 提出最近觀察到、覺得值得 SITCON 一起討論的現象或問題。
- 提出一個尚未完整的主題方向。
- 延伸其他人的 Discussion，補充不同觀點或另開分支。
- 提供文章、作品、事件、關鍵字等相關素材。

不需要先想好主題名稱，也不需要先寫完整論述。

## 討論原則

1. 原始 Discussion 盡量保留當下的想法脈絡；若想法產生明顯轉折或分支，優先透過回覆或另開 Discussion 並互相連結。
2. 提案可以被延伸、拆分、合併或重新詮釋，但整理時應保留來源與仍存在的差異。
3. 每一輪整理是「目前的共同理解」，不是不可修改的分類結果。
4. 主題方向成熟後，會再進一步檢視它與學生、資訊科技、社群、當年度脈絡及整體年會策展的關係。
